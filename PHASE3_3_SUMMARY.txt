6 REST ENDPOINTS
================================================================================

1. POST /api/suggestions/inline
   - Generate real-time inline suggestions
   - Input: code, language, cursor position, context
   - Output: List of suggestions with confidence scores

2. POST /api/suggestions/context
   - Get context-aware suggestions
   - Input: code, current method, current class
   - Output: Context-based suggestions

3. POST /api/suggestions/personalized
   - Get personalized suggestions
   - Input: code
   - Output: User preference-based suggestions

4. POST /api/suggestions/quick-fix
   - Get quick fix suggestions for errors
   - Input: code, error message
   - Output: Error-specific fixes

5. GET /api/suggestions/history/{userId}
   - Get suggestion history
   - Input: userId, limit
   - Output: List of past suggestions

6. POST /api/suggestions/apply & /reject
   - Apply or reject suggestions
   - Input: userId, suggestionId, reason
   - Output: Confirmation
